## Dena'ina Language Learning Website

Web application for learning Dena'ina, with audio and a short activity to test understanding.


## Setup
## Tools and Libraries Used
Frontend: React, Vite, Tailwind, Motion, React Router
Backend: Pandas, FastAPI, Uvicorn

## Frontend
cd frontend
npm install
npm run dev


## Backend
cd backend
pip install 
uvicorn main:app --reload
