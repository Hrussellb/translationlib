## Dena'ina Language Learning Website

Clients: Dr. Maria Williams, Prof. Donita Slawson, and Ms. Edna Standifer

Advisor: Dr. Pradeeban Kathiravelu

## Overview
This is a web application for learning Dena'ina, with audio and a short activity to test understanding. The project focuses only on the Upper Cook Inlet region for Dena'ina. The Dena'ina language faces critical endangerment from past events with only a small amount of Elders left. To preserve the language, the website contains terminologies and phrases for communicating in Dena'ina. Goal of the project is to encourage nad increase accessibility for learning Dena'ina. 

This project is part of the University of Alaska Anchorage Department of Computer Science & Engineering with associations with the Department of Alaska Native Studies.
